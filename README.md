# InLighnX_Internship_Projects



**InlighnX Internship – Offensive Cybersecurity Projects**

This repository contains the projects developed during the Offensive Cybersecurity Internship at InlighnX.
Each folder represents an individual cybersecurity tool or script.

---------------------------------------------------------

**Table of Contents**

**1. Network Scanner**
- A Python tool that scans networks using ARP requests and lists active devices.

**2. Subdomain Finder**
- Checks potential subdomains from a wordlist and identifies valid ones.

**3. PDF Password Protector**
- Creates a password-protected version of any PDF.

**4. PDF Password Decrypter**
- Attempts to recover PDF passwords using brute-force or dictionary attacks.
